# TL;DR · 无限画布画廊

## 要做什么

Web 画廊多一种视图:照片铺在一块可以自由拖动、缩放的画布上,WebGL2 渲染。一块画布,五种排布:漫游(四个方向无限循环的照片墙)、月份、相机、标签、地点(后四种把照片聚成"岛")。切换排布时照片飞到新位置。

## 你会看到的(按顺序)

1. 页头视图切换多一个图标:瀑布流、列表、**画布**。只在桌面出现。
2. 点进去是漫游:一面照片墙,往哪拖都没有尽头,松手有惯性。
3. 底部一个分段控件:漫游 · 月份 · 相机 · 标签 · 地点。点"月份",照片飞成一座座岛,视口缩到刚好装下全部。
4. 分组排布下右下角有小地图;双击某座岛,视口飞过去。
5. 点任意照片,用现有 Viewer 打开,从照片所在位置展开;关闭时收回去。
6. URL 带 `?view=canvas&arrange=month`,可以直接分享。

## 请检查这些(我替你定的)

1. **"漫游"和四个分组维度合并成底部一个分段控件。** 没有数据的维度不显示(你现在的 18 张照片没有地点,所以不会有"地点")。
2. **岛多了以后怎么摆:** 一行放满换行,整体接近视口比例。原型里的两行交错和连接虚线只适合 8 座岛,不沿用。这一条没有画稿。
3. **原型底部的月份跳转按钮不做**,改成小地图 + 双击岛飞过去。岛多了按钮放不下。
4. **一张照片有多个标签时,出现在每个标签的岛里。** 没有标签/相机/地点的照片归到最后一座"未标注"岛。
5. **分组排布缩到看全貌时不发任何请求**,用清单里的 thumbhash 当贴图;照片在屏幕上大于约 64px 才请求缩略图。漫游最小只能缩到 50%,那时照片仍会请求缩略图。
6. **放大上限:** 到缩略图发糊前为止(长边不超过缩略图像素的 1.5 倍)。
7. **画布上没有 EXIF 悬浮层和 Live Photo 悬停播放**,悬停只显示"日期 · 相机"。
8. **进入画布后筛选条(ActiveFiltersHero)和页脚不显示**,筛选仍可从页头改。
9. **只有画布模式写进 URL;** 相机位置和缩放不写。
10. **任何维度最多 60 座岛**,多出来的小组合并成“其他”;月份超过 60 个时改按年分组。
11. **引擎拆成新包 `@afilmory/photo-canvas`**,和现有的 `webgl-viewer`、`viewer-motion` 并列。

## 已知代价

中等缩放下,一屏可能要拉 100–200 张 600px 缩略图(每张 100–500KB)。靠"快速移动时不请求"和浏览器缓存缓解。要根治得让构建器多产一档小图,这次不做。

## 工作量

由我在会话里实现:大约 3–5 小时的连续工作,分两段——先是引擎加单测,再是接进页面并在浏览器里验收。10,000 张压测的帧率数字要等跑出来才知道,不达标会追加时间。
