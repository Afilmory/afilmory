## 要做什么

补完 iOS 重设计里还没换风格的部分：第一次打开时的介绍、登录、新用户建站流程，以及所有弹出层。后端不改。iPhone Duo 适配放到下一个项目。

## 你会看到什么

1. **第一次打开**：一张照片曝光开场，接着是展览、观展、暗房各一页介绍，每页一张你的照片配一句话。
2. **第 4 页是登录页**：可以用 Apple、GitHub、Google 或邮箱登录，也可以点「先逛逛别人的展」，以访客身份直接进观展。
3. **新用户登录后先建站**：一页里填展厅名，网址默认用账号名，可以改，会实时显示是否可用。
4. **权限页**：一个按钮依次弹出相册和通知两个权限请求，每个权限下面有一个预览，告诉用户给了之后会看到什么。
5. **第一卷**：直接复用暗房的冲洗卡片，选完照片开始冲洗，然后自动落到展览首页。
6. **所有弹出层**（评论、筛选、额度墙、账号、审片、CNAME）统一样式：悬浮卡片、Schola 标题加圆形关闭按钮，弹出时背后的页面变暗并轻微失焦。
7. **订阅页**：全屏，头图是你自己的一张照片，套餐竖排成展签卡。
8. **账号设置**：合并进暗房的账号 sheet，删除账号单独做成全屏流程。

## 已定的决定

| 项 | 决定 |
| --- | --- |
| 介绍页版式 | 展签：照片卡在上，文字在下（q1-a） |
| 登录页 | 和介绍页同一种版式，是介绍的最后一页（q2-a） |
| 建站 | 一页：展厅名加网址；自定义域名移到暗房（q3-a） |
| Sheet 头部 | Schola 标题加圆形关闭按钮（q4-a） |
| 进度 | 主按钮上方的小点，当前页那一点拉长（q5-a）；不用带文字的刻度 |
| 权限 | 一个按钮依次请求两个权限，每个权限配一个预览（q6-b） |
| 第一卷 | 复用暗房的冲洗卡片（q7-a） |
| 订阅页 | 照片头图加竖排展签卡；结构不变（q8-a） |
| 介绍出现时机 | 只在第一次打开时出现，账号 sheet 里可以「重看介绍」 |
| 介绍照片 | 香炉 `DSCF0842`、旅鸫 `DSC_7132`、楼阁 `IMG_0030`；不用人像 |

## 请你检查这几个我自己做的决定

1. 权限页的通知文案**只承诺「你关注的摄影师发布新照片时提醒你」**。后端现在只发这一种推送，评论、关注、冲洗完成的提醒都还没有。
2. 网址**默认用账号名**（比如 `innei`），不跟着展厅名走。原因是中文展厅名生成不了网址。网址被占用时，会给出 `innei-2` 这样的候选。
3. 登录页的「我同意条款」开关**保留**（查了提交记录，是为 App Review 加的），改成登录按钮下面一行小开关。评论区的登录也统一跳到这个全屏登录页。
4. 登录页的照片用日照金山 `IMG_5469`，相当于你挑的 3 张之外的第 4 张。
5. 建站时**不再问「你叫什么」**，名字直接用账号资料里的。
6. 权限和第一卷这两步，在展厅建好之后**盖在 Tab 上全屏显示**，因为冲洗第一卷要真正上传照片。
7. 已有账号的用户换新设备登录时，不看介绍，也不走权限和第一卷。
