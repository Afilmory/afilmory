# TL;DR · iPhone Duo 竖条与三种姿态

## 要做什么

Duo 上，系统竖条装页面按钮；三个 Tab 由我们自己画的竖向焦点条显示。四个主要页面按「合拢 / 书本态 / 全展开」各给一套布局。普通 iPhone 保持不变。

## 你会看到的（按顺序）

1. 外屏合拢：搜索、放映这类按钮进右侧系统竖条，竖条下半段是「展览 · 观展 · 暗房」焦点条。按钮不再压在状态栏下。
2. 书本态（半合）：照片详情左页照片、右页信息；点评论，右页换成评论。印样、观展卡片、暗房图库都按每页一栏排，没有东西压在折痕上。
3. 书本态暗房：左页冲洗台 + 用量 + 统计，右页入口；点入口整屏推入。
4. 全展开（摊平）：
   - 详情：照片约 2/3，信息窄栏约 1/3；
   - 印样：整宽排；
   - 观展：三列；
   - 暗房：像「设置」，左侧列表 1/3，右侧显示选中项。
5. 切换姿态时，当前照片、滚动位置、选中项都保持不变。

## 已定

| 问题 | 决定 |
| --- | --- |
| Tab 放哪 | 我们自己的竖向焦点条（vb1-B） |
| 焦点条位置 | 同一条边，系统竖条下半段（vb2-C） |
| 按钮怎么进竖条 | 导航栏显示，但不放标题、背景透明（小实验已验证） |
| 详情展开 | 左照片右信息，全屏按钮在竖条（vb3） |
| 展开时的评论 | 右页原地替换（vb4-B） |
| 印样 / 观展 | 书本态每页一栏（vb5-B） |
| 暗房书本态 | 左「正在发生」，右「去哪里」；子页整屏推入（vb6、vb7-A） |
| 全展开 | 主次分栏；暗房两栏，参照「设置」（vb8–vb11 第 2 版） |
| 观展竖条 | 不加搜索按钮，只放访客「登录」；New Rolls 和 Galleries 都按 2 / 3 列排 |

## 请检查这些（我替你定的）

1. 拜访别人的图册时，「关注」在竖条里只显示图标，文字作为无障碍标签保留。
2. 书本态印样里，年份分隔占一整行，文字放在左页。
3. 印样的「∞ 地图」层级两种姿态都整宽显示。
4. 展览顶部的开场照片（没画稿）：书本态照片在左页、文字在右页；全展开整宽。
5. 本轮不改 sheet、登录、引导、配额墙、订阅页，留到下一份 spec。
6. 姿态读数为「未知」但检测到折痕时，按书本态处理。
7. 暗房图库的「选择」按钮留在内容区帧数旁，不进竖条；不加筛选（板上那条便签写错了）。
8. 详情开着全屏或评论时合上手机：退出全屏，评论回到信息，外屏显示手机版布局。

## 时间

Agent 实施大约 1 个工作日，约 10 个任务，含测试。验证内屏需要你在 Simulator 里展开 Duo 一次，约 1 分钟；验收看图约 15 分钟。
