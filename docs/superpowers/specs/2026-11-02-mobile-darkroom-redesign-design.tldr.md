## 要做什么

把 iOS App 改成三个 Tab：**展览 · 观展 · 暗房**。换一套新的字体和配色，强调色从照片里取，所有转场都用「对焦」来表达。不需要改后端。

## 你会看到什么

1. **打开 App**：一张随机照片像曝光一样，从中心张开，先过曝，再对上焦。
2. **往下滑**：照片按拍摄日剪成胶片条，滚动时远处的行轻微失焦。
3. **刻度「日 · 月 · 年 · ∞」**：切换总览的粒度。∞ 是地图，照片会从胶片条上飞到地图上，地图卡片可以全屏。
4. **点一张照片**：照片飞到全屏，详情在两档的 sheet 里。
5. **放映**：点「放映」按钮，从按钮的位置圆形展开，自动一张一张播放。
6. **观展**：「新冲洗 / 展厅」两页可以左右滑动切换，卡片按照片原始比例拼版。点头像进入对方的展厅，进场会重放曝光。
7. **暗房**：「选择照片」→ 审片 → 开始冲洗。照片先是负片，上传过程中逐渐显影成正片。

## 已定的决定

| 项 | 决定 |
| --- | --- |
| Tab | 展览 · 观展 · 暗房；地图并入展览的 ∞ 档 |
| 首屏 | 开场一帧 + 印样 + 焦平面滚动（H1） |
| 详情 | 照片为主体 + 两档 sheet，同心圆角 |
| 字体 | Schola（展品）、SF Pro（界面）、SF Mono（EXIF）、思源宋体子集（App 自带的中文标题） |
| 颜色 | 深色底；强调色从照片里取，不设品牌固定色 |
| 观展 | 两页左右滑；按原比例拼版；不做指纹卡 |
| 暗房 | 上传是主角，冲洗时负片显影；其余是原生列表 |
| 后端 | 不改 |

## 请你检查这几个我自己做的决定

- 开场照片**每次冷启动随机换一张**，不是每天一张，所以文案是「开场」，不是「今日开场」。
- 取色算法和它的阈值，以及取不到颜色时退回暖白。
- 放映每 3.6 秒换一张。
- 画板上暗房「站点」页里的「强调色跟随照片」开关**不做了**，因为它需要后端新增一个设置项。
- 现有功能的去向：搜索和筛选放在展览顶栏；套餐、赞助、清除缓存、删除账号放进暗房的「账号」分组；额度警告放在上传区下面。
- 详情页保留现在的左右翻页、双指缩放、实况照片和下拉关闭。sheet 展开时暂停翻页。
- 点别人照片的「地点」，打开那位摄影师展厅的 ∞ 档。
- 未登录的访客只能看到观展里的「展厅」。
- 开了「减弱动态效果」的用户，模糊和缩放动画改成淡入淡出。焦平面滚动如果掉帧，改成只变透明度。

## 你已经定的

- **思源宋体**：只提取 App 自带文案用到的字，按简体、繁体、香港繁体、日文、韩文五个地区各出一份小字体。用户自己写的文字（标签、标题、展厅名、评论）一律不用衬线体，中文走系统字体。
- **英文名**：Exhibition / Viewing / Darkroom、Contact Sheet、Project、New Rolls 等，照我提的这套用。

## 分几期，每期多久

按一个人全职估算，时间是粗估：

| 期 | 内容 | 预计 |
| --- | --- | --- |
| 1 | 设计基础：字体、颜色、动效、取色、三个 Tab | 2–3 天 |
| 2 | 展览 + 详情页 + 放映 + 地图 | 5–7 天 |
| 3 | 观展 | 3–4 天 |
| 4 | 暗房 + 上传显影 | 3–4 天 |

合计大约 3 周。每一期结束都要通过单元测试，并在模拟器里截图、录屏验收。
