# Matrix ICC fixtures

`srgb-matrix.icc` is a 588-byte sRGB display profile generated by LittleCMS 2,
using `generate-srgb-icc.c`.
It contains matrix colorants adapted to ICC PCS
D50, shared type-3 parametric sRGB tone curves, and the chromatic adaptation tag.
The browser must process those curves; the gain-map GPU transform uses the
already-adapted D50 colorants and must not apply `chad` again.

To regenerate, compile the C helper with `-llcms2` (add your local include and
library paths), then pass `srgb-matrix.icc` as its output path.
Profile generation
timestamps may change, so the binary is checked in for deterministic test runs.

`gainmap-icc.jpg` contains the same AV1-independent synthetic grayscale JPEG
planes as `gainmap.jpg`. `python3 generate-jpeg-icc.py` inserts the real profile
into both JPEG planes as one ICC APP2 segment each, without transcoding.
`jpeg-icc-reference.json` is the metadata, orientation, matrices and gamut flag
from the unmodified `jpeg-gainmap.ts` at upstream commit `9a0413ddefe02da95bea9218cb7961b09e47b143`.
It deliberately records
the old implementation's output to detect refactor drift.
The actual compressed
JPEG pixels are unchanged; browser tests can compare the legacy/current paths.

These fixtures contain no photos or private metadata.
The profile is generated
by the public LittleCMS sRGB constructor, not copied from a vendor's profile.
